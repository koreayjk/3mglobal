# Recall — 단어부터 그림, 공식까지. 공부한 건 오래 남게.

로그인 없이 브라우저에서 바로 쓰는 **무료 간격 반복 암기 앱 (MVP)** 입니다.
카드 만들기·복습·기록·백업은 모두 이 기기(IndexedDB)에서 동작하고, **AI 자료 정리는 선택 기능**입니다.

> 이 폴더(`recall/`)는 저장소의 기존 정적 사이트(루트 `index.html`)와 독립된 앱입니다.

## 기능

| 영역 | 내용 |
|---|---|
| 소개 | 사용 예시, 원리 설명용 망각 곡선(복습 버튼으로 곡선 변화 체험), 무료·로컬 저장 안내 |
| 오늘 | 오늘 예정 카드 수, 오늘 복습한 수, 5분 학습(최대 12장), 최근 덱, 최근 7일 복습량 |
| 자료실 | 덱·자료 관리, 검색, 정리 노트(저장을 선택한 AI 결과) |
| 만들기 | 질문·답변(역방향은 선택), 빈칸(빈칸마다 별도 카드), 이미지 가리기(마스크마다 별도 카드), 이미지 식별, CSV 가져오기, 사진·PDF로 AI 정리 |
| 복습 | 질문 먼저 → 생각/입력 → 정답 공개 → 다시/어려움/보통/쉬움, 힌트 사용 기록, 서술형은 모범 답을 보고 자기 평가(문자열 일치 판정 없음), "다시"는 같은 세션 뒤에 재출제 |
| 모드 | **오늘 복습**(일정 갱신) / **자유 연습**(기본: 기록만, 일정 변경 없음. 원할 때만 반영 선택) |
| 기록 | 실제 로그로 계산 가능한 지표만 표시(복습량, 자기 평가 분포, 예정량, 어려운 카드) |
| 설정 | 한국어/English, 하루 새 카드 수, 애니메이션 줄이기, JSON 백업·복원(병합/교체), 영구 저장 요청, 전체 삭제 |

### 복습 일정
- 공개 오픈소스 FSRS 구현 [`ts-fsrs`](https://github.com/open-spaced-repetition/ts-fsrs) 를 **기본 파라미터**로 사용합니다. 사용자 데이터로 파라미터를 최적화하지 않으며, 일 단위 간격만 씁니다(`enable_short_term: false`).
- 계산은 `src/scheduler/index.ts` 에 격리되어 있고 화면 코드와 분리됩니다.
- 카드별 `dueAt`, 상태, 평가 이력(`ReviewLog`), 힌트 사용 여부를 저장합니다. 같은 노트의 카드(빈칸·마스크)도 일정은 독립입니다.
- 평가 저장은 카드 갱신 + 로그 추가를 **하나의 IndexedDB 트랜잭션**으로 처리하고, `(sessionId, attemptKey)` 로그 id 와 카드 `revision` 으로 재렌더링·새로고침·중복 클릭에 의한 이중 저장을 막습니다.
- 같은 세션에서 "다시"로 재출제된 카드의 재확인은 기록만 남기고 일정은 다시 바꾸지 않습니다.

### 데이터 구조 (`src/types.ts`)
`Deck`, `Note`(원자료), `Card`(복습 카드: 노트에서 파생), `ReviewLog`, `Settings`, `StoredImage`, `Material`(저장을 선택한 AI 정리 노트).
마스크는 이미지 기준 **0~1 정규화 좌표**로 저장되어 화면 크기·회전과 무관합니다. 백업 JSON 에는 `schemaVersion` 이 있고, 가져오기 전에 구조·참조 무결성을 검사합니다.

## 실행 방법

```bash
cd recall
npm ci
npm run dev          # http://localhost:5173  (AI 는 .env 없으면 꺼짐)
npm run verify       # 타입 검사 + i18n + 테스트 + 빌드 + 번들 비밀 검사
npm run build && npm run preview   # 프로덕션 빌드 확인(PWA/오프라인)
```

## AI 자료 정리 (선택)

흐름: **자료 추가 → 추출 내용 확인 → AI 정리 → 문제 미리보기 → 저장**

- 사진 촬영/선택, PDF, 텍스트 파일. 여러 장 순서 변경·회전·자르기·취소·재시도, 형식/용량/페이지 제한 표시. 카메라가 안 되면 파일 선택으로 대체.
- PDF 텍스트는 **브라우저 안에서** 추출합니다(외부 전송 없음). 글자가 없는 이미지는 직접 입력하거나, 확인 대화상자에서 동의한 경우에만 AI 로 글자를 읽습니다.
- 결과: 제목·주제, 개념, 용어·정의, 과정·순서·비교, 핵심 포인트, 질문·답변/빈칸/이미지 식별 카드. 원문 페이지 번호가 출처 칩으로 연결되고 원문과 나란히 볼 수 있습니다.
- **자동 저장하지 않습니다.** 사용자가 수정·삭제·선택한 카드만 저장합니다. "확인 필요" 카드는 기본으로 선택 해제됩니다. 이미지 가리기 영역은 자동 생성하지 않습니다(정확성을 확인할 수 있을 때 추가 예정).
- 자료 안의 지시문은 시스템 명령이 아니라 **분석 대상 데이터**로만 취급합니다(`api/_lib/prompt.ts`: 구분자 위조 방지, 구조화 출력 강제, 응답 재정제).

### 구조
```
브라우저 → POST /api/analyze (Vercel 서버리스, DB 없음) → api/_lib/providers/{anthropic|openai|mock}.ts → AI 제공자
```
- API 키는 **서버 환경변수에만** 있습니다. `VITE_*` 에는 비밀 값을 넣지 않습니다. `npm run check:secrets` 와 CI 가 번들을 검사합니다.
- 키/제공자가 없으면 `/api/health` 가 `aiEnabled:false` 를 돌려주고 **AI 기능만 꺼집니다.** 직접 만들기·복습은 그대로 동작합니다.
- 제공자·모델은 환경변수로 교체합니다. 새 제공자는 `providers/` 에 어댑터를 추가하면 됩니다.
  - `anthropic`: 공식 `@anthropic-ai/sdk`, 구조화 출력(`output_config.format`). 기본 모델 `claude-haiku-5-5` (바꾸려면 `AI_MODEL`).
  - `gemini`: Google Gemini API(`generateContent`, 키는 `x-goog-api-key` 헤더). 기본 모델 `gemini-3.8-flash`(`AI_MODEL` 로 변경. Google 이 모델을 신규 사용자에게 종료하면 404 가 나므로 그때는 `AI_MODEL` 만 바꾸세요). **무료 사용 구간(free tier)이 있습니다.** 아래 "Gemini 무료 구간" 참고.
  - `openai`: Chat Completions + JSON 스키마 응답. `AI_BASE_URL` 로 호환 서버 지정 가능. `AI_MODEL` 필수.
  - `mock`: 개발용. **입력과 무관한 고정 예제**이며 UI 에 눈에 띄는 "개발용 예제 결과" 배너가 항상 붙습니다.

### 환경변수 (`.env.example` 참고, 값은 모두 비어 있음)
| 변수 | 설명 |
|---|---|
| `AI_PROVIDER` | `anthropic` / `openai` / `gemini` / `mock` (비우면 AI 꺼짐) |
| `AI_MODEL` | 모델 ID |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `GEMINI_API_KEY` | 사용하는 쪽만. **서버에만** (Gemini 는 `GOOGLE_API_KEY` 도 인식) |
| `AI_BASE_URL`, `AI_EFFORT` | 선택 |
| `AI_ENABLED=false` | 긴급 차단 스위치 |
| `AI_ACCESS_CODE` | 설정하면 앱 설정 화면에서 같은 코드를 입력한 사용자만 AI 사용 (이 기기에만 저장, 백업 제외) |
| `AI_ALLOWED_ORIGINS` | 다른 도메인(GitHub Pages 등)에서 호출 허용할 출처(쉼표 구분). 비우면 같은 도메인만 |
| `AI_MAX_OUTPUT_TOKENS` `AI_MAX_PAGES` `AI_MAX_IMAGES` `AI_MAX_TEXT_CHARS` | 요청당 제한 (기본 6000 / 12 / 6 / 60000) |
| `AI_RATE_LIMIT_PER_HOUR` `AI_DAILY_REQUEST_CAP` | IP당 시간당(기본 20), 하루 총 요청(기본 300) |
| `VITE_AI_API_BASE` | (비밀 아님) 정적 호스팅에서 별도 AI 서버 주소 |
| `VITE_BASE` | (비밀 아님) 하위 경로 배포 시 base |

### Gemini 무료 구간 (2026-10 공식 문서 기준, 바뀔 수 있음)
- Google AI Studio 에서 API 키를 만들고 `AI_PROVIDER=gemini`, `GEMINI_API_KEY=…` 를 서버 환경변수에 넣으면 됩니다. 이미지 입력을 지원하는 무료 모델(2026-10 문서 기준 예: `gemini-3.8-flash`, `gemini-3.5-flash-lite`)을 `AI_MODEL` 로 고를 수 있습니다.
- **무료 구간에서는 입력 내용이 Google 제품 개선에 사용될 수 있다**고 문서에 명시돼 있습니다(유료 구간은 아님). 앱은 이 경고를 전송 전 안내에 표시하지만, 민감한 자료는 보내지 마세요.
- 한도는 **프로젝트 단위**이고 모델·계정 상태에 따라 달라지며 자주 바뀝니다. 정확한 값은 AI Studio 의 rate limit 화면에서 확인하세요. 한도를 넘으면 앱에 "AI 서비스가 혼잡해요" 오류가 보입니다. 공개 사이트에서는 모든 사용자가 한 프로젝트의 한도를 나눠 쓰므로 `AI_ACCESS_CODE` 를 권장합니다.
- 생각(thinking) 토큰이 출력 한도에 포함되는 모델에서 "결과가 너무 길어요"가 나오면 `AI_MAX_OUTPUT_TOKENS` 를 늘리세요(예: 12000).
- 구조화 출력 필드(`responseJsonSchema`)를 모델이 거절하면 스키마를 프롬프트로 옮겨 한 번 재시도합니다. 실제 Gemini 호출은 이 개발 환경에 키가 없어 가짜 서버로만 테스트했습니다.

### 비용·개인정보·남용 방지 — 정확한 한계
- 분석 버튼을 누른 자료만 전송됩니다. 전송 전에 페이지/글자/이미지 수와 "외부 AI 서비스로 전송" 안내를 보여주고, 글자 추출은 별도 동의 대화상자를 거칩니다. 이미지는 긴 변 1280px 로 줄여 보내고, "이미지도 함께 전송"은 기본 꺼짐입니다.
- 서버는 원문·추출 텍스트·이미지를 **로그에 남기지 않습니다**(실패 시 오류 코드만 기록). AI 제공자 쪽 보관 정책은 별도이므로 민감한 자료는 보내지 마세요.
- 서버에서 형식·크기·페이지 수·글자 수·출력 길이를 검증하고, 중복 클릭은 UI 에서 막습니다. 실패 시 원인과 재시도 가능 여부를 표시합니다.
- 인증이 없는 공개 호출이므로 보호 장치는 **다층·최선 노력**입니다: 같은 출처 검사 또는 `AI_ALLOWED_ORIGINS`, 선택적 `AI_ACCESS_CODE`, IP당 시간당 제한, 일일 총량 제한, 요청 크기·출력 토큰 상한.
  **IP·일일 제한은 서버리스 인스턴스 메모리에 있으므로(DB 없음) 인스턴스가 여러 개이거나 재시작되면 초기화됩니다.** 따라서 확정적인 지출 상한은 반드시 **AI 제공자 콘솔의 월 예산/사용 한도**로 설정하세요(운영자의 책임). 공개 배포라면 `AI_ACCESS_CODE` 사용을 권장합니다.
- "무제한 무료 AI"가 아닙니다. 앱 안에서도 제한을 안내합니다.

## GitHub 연결과 Vercel 배포

이 환경에서는 실제 연결·배포를 하지 않았고 코드·설정만 준비했습니다. (이미 이 코드가 GitHub 저장소에 올라가 있다면 1단계는 건너뛰세요.)

1. **GitHub 저장소**: 이 폴더를 포함한 저장소를 GitHub 에 push 합니다. `.gitignore` 가 `.env*`(단 `.env.example` 제외), 키 파일, 백업/업로드 파일을 제외합니다. 사용자 학습 자료를 GitHub 에 저장하지 않습니다.
2. **Vercel**: Vercel → *Add New Project* → 저장소 import.
   - **Root Directory: `recall`** (저장소 루트가 아님)
   - Framework: Vite (`vercel.json` 에 지정됨), Build `npm run build`, Output `dist`
3. **환경변수**: Vercel → Settings → Environment Variables 에 위 표의 서버 변수를 입력(최소 `AI_PROVIDER`, `AI_MODEL`, 해당 API 키). 비밀 값을 `VITE_` 로 만들지 마세요.
4. 배포 후 앱 → 설정 → *AI 자료 정리* 에서 상태를 확인합니다. 키가 없으면 "AI 서버가 설정되어 있지 않아…"가 보이고 나머지 기능은 정상입니다.
5. 제공자 콘솔에서 **월 지출 한도**를 설정하고, 공개 배포라면 `AI_ACCESS_CODE` 를 설정하세요.
6. CI: `.github/workflows/recall-ci.yml` 이 push/PR 마다 타입 검사·i18n·테스트·빌드·번들 비밀 검사를 실행합니다.

### GitHub Pages
GitHub Pages 는 **정적 파일 호스팅**이라 비밀 API 키를 쓰는 서버 함수를 실행할 수 없습니다. 전체 AI 기능의 기본 배포는 Vercel 입니다.
Pages 로도 배포하려면 `VITE_AI_API_BASE=https://<vercel 앱 도메인>` 으로 빌드하고(별도 AI API 서버 주소만 설정, 키는 프론트엔드에 넣지 않음) Vercel 쪽에 `AI_ALLOWED_ORIGINS=https://<계정>.github.io` 를 설정합니다. 하위 경로면 `VITE_BASE=/<저장소>/recall/` 도 지정하세요. AI 서버 없이 정적으로만 배포해도 **수동 카드 생성과 복습은 모두 작동**합니다. 기존 `deploy-pages.yml` 은 이 앱을 빌드하지 않습니다.

## 남은 제한
- 데이터는 기기·브라우저별이며 자동 동기화·계정·공유 커뮤니티는 범위 밖입니다. 브라우저 데이터 삭제 시 사라질 수 있어 JSON 백업을 권장합니다.
- 예제 자료 본문은 한국어입니다(UI만 영어 전환).
- OCR 은 AI 에 의존합니다(오프라인 OCR 없음). 이미지 가리기 자동 생성은 아직 없습니다.
- PDF 는 pdf.js 레거시 빌드를 쓰며 번들이 큽니다(PDF 사용 시에만 로드, PWA 캐시에는 포함).
- 서버 측 사용량 제한은 최선 노력이며 확정적 지출 상한은 제공자 콘솔에서 설정해야 합니다.
- 실제 AI 제공자(Anthropic/OpenAI)와의 라이브 호출은 이 개발 환경에서 키가 없어 검증하지 못했습니다. 요청/응답 경로는 가짜 서버와 mock 으로만 테스트했으니 키를 설정한 뒤 소량으로 먼저 확인하세요.
